# Code of Conduct

We want PixyTalk's issues, pull requests, and discussions to be useful and welcoming.

- Be respectful and considerate of different experience levels and backgrounds.
- Critique ideas and code with specific, constructive feedback.
- Assume good intent, ask for clarification, and acknowledge mistakes.
- Respect privacy. Do not publish personal information, credentials, or customer data.
- Harassment, discrimination, threats, sexual harassment, and personal attacks are not acceptable.

This applies to project spaces and when representing the project. Maintainers may edit or remove harmful content, limit participation, or block repeated or serious violations. They should explain moderation decisions when doing so is safe and respect the privacy of people involved.

To raise a conduct concern, contact the repository maintainer through a private contact method listed on their GitHub profile, if available. If no private method is listed, request one without identifying affected people or posting sensitive details publicly. A dedicated reporting channel has not yet been established.
